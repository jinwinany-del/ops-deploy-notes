=== 部署实录：在阿里云轻量上用 Docker Compose 部署个人网站 ===

【一、目标】
把本地一个静态网站用 Docker 打成镜像，通过 docker compose 编排（web + cache），
部署到一台真实的阿里云 轻量 上，实现任何联网设备（含手机）都能访问。

【二、环境与架构】
- 云服务器：阿里云 轻量，Ubuntu 24.04 LTS，2核2G，公网 IP 203.0.113.10
- 运行时：Docker + docker compose（Ubuntu 自带 docker.io 包）
- 架构：用户 --公网:80--> Docker 端口映射 --容器:80--> web 容器（nginx，自建镜像 my-web:v1）
        同一 compose 网络内的 cache 容器（redis）
- 三个文件：index.html（网页内容） / Dockerfile（构建镜像） / docker-compose.yml（编排）

【三、实施步骤】
1. 装 Docker：apt install -y docker.io docker-compose-v2；systemctl enable --now docker
2. 配国内镜像加速器（国内直连 Docker Hub 不通）：
   - 阿里云控制台「容器镜像服务 → 镜像工具 → 镜像加速器」获取专属地址
   - 写入 /etc/docker/daemon.json 的 registry-mirrors
   - systemctl daemon-reload && systemctl restart docker（校验：docker info 看 Registry Mirrors）
3. 用 heredoc 写三个文件到 /root/app
4. 构建 + 起服务：docker build -t my-web:v1 . && docker compose up -d；curl -I http://localhost 自测
5. 安全加固：
   - 安全组：入方向放行 22 / 80 / 443，其余默认拒绝
   - ufw：先 allow 22，再 allow 80/443，最后 enable（顺序：先放行 SSH 再启用）
   - 密钥登录：客户端 ssh-keygen 生成密钥对 → 公钥写入服务器 ~/.ssh/authorized_keys
     （chmod 700 ~/.ssh、600 authorized_keys）
   - 禁用密码：/etc/ssh/sshd_config 里 PasswordAuthentication no → sshd -t 校验 → systemctl restart ssh
     （依据：auth.log 里一天被暴力猜密码 324 次）
6. sshd 加 ClientAliveInterval 60 / ClientAliveCountMax 3，防连接空闲掉线

【四、踩过的坑与排查（重点）】
1. Docker 官方 apt 源在国内被重置（curl error 35 Connection reset）→ 改用 Ubuntu 自带包
2. dockerd 拉镜像不走终端的 http_proxy → 要给 docker.service 配 systemd drop-in 代理；
   且目录名必须是 docker.service.d（写成 docker.serveice.d 会被 systemd 静默忽略、不报错）
3. daemon.json 手打出现多余字符 → docker 起不来（activating auto-restart）；
   用 systemctl status docker 看报错 + cat -A 查隐藏字符
4. 国内服务器拉不到 Docker Hub（dial tcp ... i/o timeout）→ 配阿里云镜像加速器后成功
5. 端口被占用：docker run -p 8080 报 "address already in use" → sudo ss -tlnp | grep 8080 定位到系统 nginx，
   换端口或停掉占用者
6. COPY 路径写错（/uer/...、/nagix/...）→ Docker 不报错、但文件被放到无用路径，页面仍是默认欢迎页；
   靠 curl -s 看正文才暴露 → 改 Dockerfile 重新 build
7. compose 的 yaml 手打错（imgae/prots/减号）→ 报 "additional properties not allowed" /
   "did not find expected '-' indicator"
8. WSL 重启后容器不自动启动 → docker ps -a 看状态、docker start 复活（镜像一直在）

【五、成果】
- http://203.0.113.10 ：手机与电脑均可访问，页面为自建镜像提供
- 镜像分层共享（my-web:v1 仅比 nginx:alpine 大 0.1MB）
- 安全加固后 22 端口暴力尝试停止

【六、面试可讲的点】
- 镜像 / 容器 / 层 / 数据卷 概念与区别
- Dockerfile（造镜像）与 docker-compose（编排）的关系
- 端口映射格式「主机端口:容器端口」
- 双层防火墙（安全组 + ufw）、"默认拒绝"、"纵深防御"
- 密钥登录 vs 密码登录（暴力破解）
- 排查方法论：分层定位（服务 → 本机 → 防火墙 → 安全组）、以及"命令不报错 ≠ 做对了"
